Andalusi font for the site titles
=================================
Put the font file here with exactly this name:  andalusi.woff2
(if you only have a .ttf/.otf file, convert it to .woff2 first, e.g. with an online "ttf to woff2" converter)

The site then uses it automatically for the titles (class "font-maghribi").
Use only a font whose licence allows embedding it on a website ("web" / "webfont" licence).
